Set up St. Peter’s Keys

Nobody has an account on this server yet. Create the administrator account — it is the one that can add and remove everyone else.

This connection is not encrypted. The token and the password below will travel across the network in plain text.

If this server is reachable by anyone but you, stop and put a certificate in front of it first, or do this over an SSH tunnel on localhost.

Printed in the server’s console when it started, and saved beside the accounts file as setup-token.txt. Capitals and hyphens do not matter.

Letters, numbers, spaces, full stops, hyphens and underscores, up to 40 characters.

At least 8 characters. A phrase you will remember is better than something short and clever.

This page stops working the moment an account exists. If you lose the administrator password later, the way back is node server/reset-accounts.js on the server itself — it issues a fresh token and never touches the newsletter.
